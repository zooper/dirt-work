# Pass 5 — faceted rock faces

Reference: terraced walls built from large angular blocks with flat fracture planes, a coherent vertical fracture direction, broken uneven tops, lit fronts and darker side planes.

Change (`QuarryWorld._slab_face`): each bench face is now a row of overlapping prismatic rock columns (3–7.5 m wide, full bench height) built as convex hulls with independently angled front planes, a chamfer point that splits the front into two fracture planes, leaning/broken tops and per-face shading (sun-facing fronts lighter, side planes darker). Talus blocks at the foot. Rock palette shifted cooler (slate grey). Collision unchanged (bench boxes).
